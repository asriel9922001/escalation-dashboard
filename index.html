🎯 Action Plan Summary (Discussions with IT, DLS, NO, Product Teams)

🌐 Network Issues (120,203 complaints - 29.0%)

Root Cause:

Infrastructure capacity constraints, signal propagation issues, 4G coverage gaps

Solution/Mitigation:
  • Upgrade cell tower capacity in high-complaint areas (Bandung, Semarang)
  • Implement signal optimization across 4G network
  • Expand coverage in identified dead zones
Owner: NO (Network Operations)
Timeline: Q2-Q3 2026
Proposed Actions:
  • Weekly network performance review meetings
  • Monthly coverage expansion reports
  • Target: Reduce network complaints to <20% by Q3

⚙️ IT Issues (96,531 complaints - 23.3%)

Root Cause:

Product activation system failures, registration bottlenecks, app stability issues, backend performance

Solution/Mitigation:
  • Optimize activation system performance and add redundancy
  • Improve registration flow UX and reduce manual steps
  • Stabilize MyTelkomsel and payment apps
  • Scale backend infrastructure for peak loads
Owner: IT (Infrastructure & Apps)
Timeline: Q2 2026
Proposed Actions:
  • Bi-weekly system performance audits
  • Monthly app stability reports
  • Target: Reduce IT issues to <15% by Q2 end

📱 Prepaid (76,060 complaints - 18.3%)

Root Cause:

Credit/quota inconsistencies, purchase fulfillment delays, registration blockers, spec mismatches

Solution/Mitigation:
  • Implement real-time credit/quota reconciliation system
  • Streamline prepaid registration process
  • Improve product specification clarity and documentation
  • Enhance CSR training on Prepaid solutions
Owner: Product (Prepaid Team)
Timeline: Q2-Q3 2026
Proposed Actions:
  • Weekly prepaid issue root cause analysis
  • Monthly product spec documentation updates
  • Target: Reduce Prepaid complaints to <12% by Q3

💾 DLS (50,429 complaints - 12.1%)

Root Cause:

Subscription delivery failures, feature activation delays, product spec confusion

Solution/Mitigation:
  • Fix end-to-end subscription provisioning pipeline
  • Implement automated subscription health monitoring
  • Create clear DLS onboarding flows for new users
  • Partner training on DLS offerings
Owner: DLS (Product Team)
Timeline: Q2 2026
Proposed Actions:
  • Daily subscription delivery audit
  • Weekly partner training sessions
  • Target: Reduce DLS complaints to <8% by Q2 end

💳 Postpaid (39,299 complaints - 9.4%)

Root Cause:

Billing transparency issues, unexpected charges (Bill Shock), invoice clarity

Solution/Mitigation:
  • Implement pre-charge notification system for add-ons
  • Enhance billing statements with clear usage breakdown
  • Automate billing anomaly detection and alerts
  • Improve billing CSR scripts and training
Owner: Billing & Finance
Timeline: Q2 2026
Proposed Actions:
  • Weekly billing anomaly reports
  • Monthly customer communication improvement tests
  • Target: Reduce Postpaid complaints to <5% by Q2 end
